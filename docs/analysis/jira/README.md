# Analisi Jira

Questa cartella contiene deliverable funzionali e tecnici puntuali legati a issue Jira, soprattutto per i Sub-task di Analisi e Progettazione.

I file devono usare il formato `WVERSE-<numero>.md` e includere, quando applicabile, flussi, input, stati, errori, contratti, persistenza, sicurezza, dipendenze e criteri tecnici.

Il riferimento operativo per il ciclo Jira è [JIRA_WORKFLOW.md](../../knowledge/operations/JIRA_WORKFLOW.md).

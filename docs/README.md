# Documentazione Watchverse

La documentazione è organizzata per natura del contenuto. La fonte normativa per le regole Jira resta `knowledge/operations/JIRA_WORKFLOW.md`; gli altri documenti la completano senza duplicarla.

## Indice

- [Knowledge base](knowledge/README.md): contesto stabile, decisioni, regole operative, handoff e playbook.
- [Analisi Jira](analysis/jira/README.md): analisi funzionali e tecniche puntuali collegate alle issue.
- [Specifiche](specifications/README.md): requisiti, architettura, design e sicurezza.
- [Archivio](archive/): snapshot storici, incluso il backlog precedente alla gestione operativa Jira.
- [Guide](guides/README_PRIMA_DI_INIZIARE.txt): istruzioni per utenti e sviluppo locale.
- [Changelog](CHANGELOG.md): storia delle modifiche pubblicate.

## Regola di scelta

- Se descrive un fatto stabile o una decisione operativa → `knowledge/`.
- Se spiega come svolgere un’attività ricorrente → `knowledge/playbooks/`.
- Se documenta l’analisi di una issue specifica → `analysis/jira/`.
- Se definisce come il prodotto o l’architettura devono essere → `specifications/`.
- Se guida una persona nell’uso o nell’avvio del progetto → `guides/`.
